# 📱 Gerador de QR Code Personalizado

Uma ferramenta de linha de comando feita em Python para gerar QR Codes de forma rápida e fácil para qualquer link ou texto.

## ✨ Funcionalidades

- **Interativo:** Pede ao usuário os dados para codificar e o nome do arquivo de saída.
- **Personalizável:** O código permite ajustar parâmetros como tamanho, borda e cores do QR Code.
- **Saída em Imagem:** Salva o QR Code gerado como um arquivo de imagem `.png`.
- **Interface Amigável:** Utiliza `colorama` para uma experiência de usuário clara e colorida no terminal.

## 🚀 Como Usar (Versão Executável para Windows)

1. Vá para a **[Página de Releases](https://github.com/allymonteiro/GeradorQRCode/releases)**.
2. Baixe o arquivo `gerador_qrcode.exe` da versão mais recente.
3. Dê dois cliques para executar, digite os dados que deseja e o nome do arquivo de saída!
